# hxwl-09 半导体洁净室 · 粒子采样与恢复放行台

在原洁净室巡检看板上扩展的粒子采样登记、异常停用、换班复测与放行冻结工作台。
纯前端、无新增依赖；刷新后采样、停用、复测与版本数据在本地保持一致。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式）+ 原生 CSS，localStorage 持久化，不引入任何新依赖。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5109
npm run build    # 生产构建
npm run verify   # 领域规则断言（41 项，使用 vite 自带 esbuild，无测试框架）
```

开发端口：5109

## 业务规则

### 采样单登记
字段：房间编号、ISO 等级、粒子粒径、粒子计数（粒/m³）、采样器编号、校准有效期、班次、采样时间。

### 三类异常判定（任一命中即异常）
1. **校准过期**：采样器校准有效期早于当天（到期当日仍有效）。
2. **粒径与等级不匹配**：粒径不在该 ISO 等级适用范围（如 ISO 5 不适用 0.1μm）。
3. **计数超限**：计数超过该等级该粒径的 ISO 14644-1 限值（等于限值为合格）。

异常处理：**输入原样保留**（异常值也写入采样记录），同时生成异常单，房间进入**停用**。

### 停用与复测
- 停用期间不得提交正常采样；对停用房间的提交一律识别为**复测**。
- 复测**只能换班**：复测班次与该房间上次采样班次相同将被拦截。
- 复测失败（仍命中任一异常）会重置连续合格计数，并再生成一张异常单。
- 连续 **2 次合格复测**后才允许放行。

### 放行冻结与版本更正
- 放行时**冻结**：房间状态（released）、ISO 阈值快照、两次复测读数、采样器与关联单号；异常单关闭。
- 放行冻结后不能再提交采样。
- 后续更正必须：填写**更正人与原因** → 生成**新版本**，旧版本读数与原因完整保留并标注。
- 更正只能改计数（按两次复测位次对齐，粒径不可改），且新读数仍须满足冻结阈值。

### 持久化
- 每次提交/放行/更正即时写入 localStorage（键：`hxwl-09.particle-release.v1`）。
- 刷新后以本地数据为准；结构损坏或 schema 不匹配时回落到演示种子。
- 顶部提供「重置为演示数据」「清空业务数据」。

## 演示数据时间线（种子）

- **CR-2107**（ISO 6）：白班正常采样合格。
- **CR-1201**（ISO 5）：白班计数超限停用 → 中班选错粒径（0.1μm 不适用）复测失败 → 夜班合格 1 次 → 次日白班合格 2 次，**等待放行**。
- **CR-2108**（ISO 7）：校准过期停用 → 更换采样器后夜班合格 1 次，**仍需再复测**。
- **Y-0302**（ISO 8）：计数超限停用 → 夜班/白班两次合格 → 已放行，并留有一次 v2 读数更正（v1 旧值保留）。
