# hxwl-09 半导体洁净室粒子采样与恢复放行台

粒子采样单登记、异常停用、换班复测、放行冻结与版本更正的本地工作台。

## 技术栈

React 19 + Vite + TypeScript + CSS，无新增依赖（不引入状态管理/UI 库）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 业务流程

1. **采样单登记**：房间、ISO 等级（随房间带出）、粒径、计数、采样器编号、校准有效期、班次。
2. **判定（三类异常，纯函数）**：
   - 校准过期（以登记日期比较校准有效期）；
   - 粒径与等级不匹配（该 ISO 等级不考核所选粒径，限值取 ISO 14644-1:2015）；
   - 计数超限（计数高于该等级该粒径限值）。
3. **异常不停单**：命中任意异常时输入照样保留，生成异常单，房间进入**停用**。
4. **停用期**：不得提交正常采样；复测只能换班（与上一次提交不同班次）；
   连续两次合格复测后，手动**放行**。
5. **放行冻结**：冻结房间、阈值表与相关读数（异常单 + 两次复测），关闭未结异常单，
   房间进入已放行，形成放行台账 v1。
6. **更正版本**：放行后只允许在台账上更正读数（计数/采样器/校准有效期），
   必须填写原因；每次更正基于放行时冻结的阈值与放行日期重新判定，生成新版本，旧版本只读保留。
7. **刷新一致**：全部状态写入 localStorage（`hxwl09-particle-station-v1`），
   采样、停用、复测、放行与版本链刷新后保持一致。

## 目录分层

```
src/
  data/reference.ts        资料：班次、粒径、ISO 限值表、房间台账
  domain/
    types.ts               领域模型
    clock.ts               本地日期/时间工具
    judgment.ts            判定纯函数（校准/粒径/计数、冻结阈值重判）
    workflow.ts            状态机：提交/停用/复测/放行/更正 + 守卫 + 演示场景
  storage/repository.ts    localStorage 读写与结构校验
  ui/
    hooks/useStation.ts    页面状态钩子（流程层 ↔ 存储层）
    components/            Header/指标/房间台账/采样表/异常单/放行版本
  App.tsx                  页面装配
```

资料、判定、本地存储与页面四层互不越界：UI 不直接读写 localStorage，
判定函数不依赖 React。首次打开自动载入内置演示场景（覆盖异常→停用→换班复测→放行→更正），
可通过页脚按钮恢复演示或清空本地数据。
